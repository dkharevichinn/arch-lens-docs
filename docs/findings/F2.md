# F2 — Untested module

| Field | Value |
|---|---|
| Code | `F2` |
| Class | `trigger` |
| Analyzer | `TestTopologyAnalyzer` |
| Commands | `map` and `gate` (unless `knownFindings`) |

## When it fires

A scored module with **no inbound type edge from any `role=test` assembly**. Shared modules are included: an isolated kernel with no tests fires F2.

Fingerprint: `ForTypeEdge("F2", moduleId, "", [])`. Message: `untested module: {module}`.

Host/test modules are not scored, so they never appear.

## Example

New `Billing` feature with contracts + implementation and zero test project references → F2. Tests that only exercise `Billing` through `App.Host` still count if the test assembly has type edges into Billing types.

## How to fix

Add a test assembly (`Billing.Tests`) that references the **contract** (preferred, see [F1](F1.md)) or, for a shared kernel, a focused test project.

## What not to do

- Do **not** add a dummy `Assert.True(true)` type that happens to name a Billing type in a field just to create an edge.
- Do **not** silence F2 for every new module as policy; it is the reminder to attach tests before the feature hardens.

See also [F1](F1.md), [P3](P3.md).
