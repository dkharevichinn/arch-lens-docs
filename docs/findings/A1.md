# A1 — Implementation bypasses a contract

| Field | Value |
|---|---|
| Code | `A1` |
| Class | `invariant` → **[block](../gates/block.md)** |
| Analyzer | `BoundaryAnalyzer` |
| Commands | `map` (snapshot finding) and `gate` (unless fingerprint is in `knownFindings`) |

## When it fires

A type-level edge whose **source is not** role `contract`, and the pair of assembly roles is illegal under the modular-monolith table.

Host and test **sources** are skipped (composition roots and tests may see implementations). Intra-module edges are allowed except `contract →` anything else in the same module (that case is [A2](A2.md), not A1).

**Foreign targets allowed** for implementation / infrastructure / ui: `contract` and `shared` only. Shared may depend only on shared. Anything else from a non-contract source is A1.

Typical messages: `{from} -> {to} bypasses the contract`.

Fingerprint: `ForTypeEdge("A1", fromTypeId, toTypeId, sorted kind names)`. Evidence lists the type pair and per-kind weights (`call`, `fieldType`, …).

## Example

Gameplay implementation calls Account's cache instead of `Account.Contracts`:

```csharp
// Gameplay/ScoreService.cs  (role: implementation)
public sealed class ScoreService
{
    public void Save(Account.TokenCache cache) { } // A1: implementation → foreign implementation
}
```

```mermaid
flowchart LR
  G["Gameplay (implementation)"] -->|call| A["Account (implementation)"]
```

Legal alternative:

```csharp
public sealed class ScoreService
{
    public void Save(Account.Contracts.IAuth auth) { } // implementation → foreign contract
}
```

Shared depending on a feature implementation is also A1 (`SharedKernel -> Account bypasses the contract`). UI depending on another module's implementation is A1.

## How to fix

1. Depend on the **other module's contract** (or on `shared`), not its body.
2. If the needed type is not on the contract, **move the type** (or a new port) into `X.Contracts` / shared — then expect [A4](A4.md) / [A5](A5.md) / [A6](A6.md) review, not a silent dump of the whole implementation assembly into Contracts.
3. If this is composition, put the wiring in a YAML-declared **host** (`role: host`). Host sources are not scored for A1.
4. If the two assemblies are really one module, **name them on the same module id** (convention `X` + `X.Contracts`, or YAML `module:`).

## What not to do

- Do **not** add `[InternalsVisibleTo]` so the implementation can see `internal` types next door — that is [A7](A7.md) if the friend is not a test assembly.
- Do **not** mark the source assembly `host` just to dodge the rule. Host is the composition root, not a dump for leftover projects.
- Do **not** copy fingerprints into `knownFindings` unless this edge is **accepted debt**. Baseline freeze is for the first snapshot of a brownfield repo, not for each new bypass.
- Do **not** make the target type `public` on the implementation and call that a contract. A1 cares about **roles**, not C# `public`.

See also [A2](A2.md), [A7](A7.md), [G1](G1.md).
