# D2 — Disconnected type islands

| Field | Value |
|---|---|
| Code | `D2` |
| Class | `trigger` |
| Analyzer | `CohesionAnalyzer` |
| Commands | `map` and `gate` (unless `knownFindings`) |

## When it fires

Undirected graph of the module's types (any type edge either way). Weakly connected components: fires if there are **≥ 2** components **and** the **second largest** has **≥ 3** types. Lone leftover types do not fire.

Requires N ≥ 4 (same skip as [D1](D1.md) — cohesion is only computed then).

Fingerprint: `ForTypeEdge("D2", moduleId, "", [])`. Message: `disconnected islands: {module}`. Island count is `cohesion[module].islands`.

## Example

`Account` contains a 10-type auth cluster and a 4-type billing cluster with no edges between them → D2. A 20-type cluster plus one unused enum does **not** fire.

## How to fix

Move the smaller island to its own module (with a contract if others need it), or wire a real collaboration if they were supposed to be one feature.

## What not to do

- Do **not** add a dummy `AccountFacade` that references both islands just to connect the graph.
- Do **not** ignore D2 because D1 sparse already fired — D2 is the split plan.

See also [D1](D1.md), [D3](D3.md), [P3](P3.md).
