## When it fires

`propagationCost = (sum over modules of reachable module count including self) / N²`. Reachability follows directed inter-module edges.

Disconnected graph: each node reaches only itself → `1/N`. A complete reachability clique → `1`.

Fires when current **>** baseline. Fingerprint: `ForTypeEdge("B4", "", "", [])`.

## Example

Four modules in a line `A→B→C→D` have smaller propagation than the same four with extra skip edges `A→C`, `A→D`, `B→D`. Adding a back edge that closes a cycle can make **everyone** reachable from everyone — cost jumps toward 1.

## How to fix

Keep the module DAG **shallow and narrow**: few long reachability chains, no cycles ([B1](B1.md)), no god row that everyone can reach through ([B7](B7.md)).

## What not to do

- Do **not** add a “utility” module that everyone references **and** that references back. That maximizes propagation.
- Do **not** confuse a drop in N (deleting a module) with an architecture win if the remaining graph is fully connected.
