# A5 — Logic in a contract assembly

| Field | Value |
|---|---|
| Code | `A5` |
| Class | `trigger` |
| Analyzer | `ContractQualityAnalyzer` |
| Commands | `map` and `gate` (unless `knownFindings`) |

## When it fires

Two independent signals, **one rule code**:

1. **Concrete class** in a contract assembly: `kind == "class"`, not abstract, not static. Records, structs, enums, interfaces, static classes, and abstract classes do **not** fire this signal.
2. **`EdgeKind.Call`** where **both** endpoints are in `contract` assemblies (same module or different).

Concrete finding: fingerprint `ForTypeEdge("A5", typeId, "", [])`, message `concrete class in contract: {id}`.

Call finding: `ForTypeEdge("A5", fromTypeId, toTypeId, ["call"])`, message `contract call {from} -> {to}`.

Static extension classes in Contracts are the supported place for trivial helpers; they are not A5.

## Example

```csharp
// Account.Contracts/AuthHandler.cs
public sealed class AuthHandler // A5: concrete class in contract
{
    public void Login() { }
}
```

```csharp
// Account.Contracts/IAuth.cs
public interface IAuth
{
    void Login();
}

public static class AuthExtensions // not A5 (static class)
{
    public static void LoginOrThrow(this IAuth auth) => auth.Login(); // A5 if this is a Call to another contract type
}
```

A contract method body that calls another contract type is the second signal — contracts should be shapes, not call graphs.

## How to fix

1. Replace concrete handlers with **interfaces** (or abstract classes if you truly need a base port). Put implementations in the implementation assembly.
2. Move call-graph behavior (validation pipelines, mapping) out of `*.Contracts`.
3. Keep DTOs as `record` / `struct` / enum — those are not this rule's concrete-class signal.

## What not to do

- Do **not** mark the class `abstract` with empty members just to dodge A5. If it has behavior, it is in the wrong assembly.
- Do **not** silence A5 because “it's only a DTO class”. Use a record; a concrete class in Contracts is a magnet for logic.
- Do **not** convert calls into `fieldType` edges by storing the other contract as a field and calling from implementation — that's the correct split, not a cheat: **calls must leave the contract**.
