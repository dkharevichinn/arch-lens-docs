# E2 — Dead implementation type

| Field | Value |
|---|---|
| Code | `E2` |
| Class | `trigger` |
| Analyzer | `TypeSmellAnalyzer` |
| Commands | `map` and `gate` (unless `knownFindings`) |

## When it fires

Scored type, role **implementation or infrastructure**, **fan-in 0**, and the type id is **not** a non-test DI `ServiceTypeId` or non-null `ImplementationTypeId` (`BindingSemantics.IsContainerConsumer`).

Contract, UI, shared, host, test are excluded. Cap 20, Ordinal typeId.

Fingerprint: `ForTypeEdge("E2", typeId, "", [])`. Message: `dead type: {typeId}`.

A type that is only constructed in a host registration is **not** dead. A type nobody references and that is not in the container **is**.

## Example

```csharp
// Account/LegacyParser.cs
internal sealed class LegacyParser { } // no inbound edges, not registered → E2
```

## How to fix

Delete it, or register/use it, or keep it as a deliberate unused export **on a contract** (then it is not E2). If it is only used from tests, that inbound edge from `role=test` still counts as fan-in **if the test type is scored** — tests are not scored, so test-only product types look dead. Move the type to the test project or stop shipping it.

## What not to do

- Do **not** add a dummy `AddSingleton<LegacyParser>()` in production DI just to silence E2.
- Do **not** make it `public` on a contract without consumers ([G2](G2.md)/[A4](A4.md)).

See also [P3](P3.md), [R2](R2.md).
