# D1 — Relational cohesion H outside [1.5, 4]

| Field | Value |
|---|---|
| Code | `D1` |
| Class | `trigger` |
| Analyzer | `CohesionAnalyzer` |
| Commands | `map` and `gate` (unless `knownFindings`) |

## When it fires

For a scored module with **N ≥ 4 types**:

- `R` = sum of weights of type edges with **both** ends in the module
- `H = (R + 1) / N`

Fires if `H < 1.5` (sparse: `sparse cohesion`) or `H > 4` (dense: `dense cohesion`).

Fingerprint: `ForTypeEdge("D1", moduleId, "", [])`. `H` is `cohesion[module].h`.

Modules with fewer than 4 types are skipped.

## Example

Four types and no internal edges: `H = 1/4 = 0.25` → sparse. Four types fully meshed with heavy call weights can exceed 4 → dense (often a god-class clique, see [E1](E1.md)).

## How to fix

- **Sparse:** the module is a bag of unrelated types — split islands ([D2](D2.md)) into modules, or add the missing internal structure if they really collaborate.
- **Dense:** break the clique: extract types, stop every type from talking to every other type.

## What not to do

- Do **not** add spurious internal calls to raise H, or delete edges by using `dynamic`/reflection so the extractor cannot see them.
- Do **not** merge two sparse modules to change N without merging their purposes.

See also [cohesion](../metrics/cohesion.md), [D2](D2.md).
