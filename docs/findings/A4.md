# A4 — Contract surface ratchet

| Field | Value |
|---|---|
| Code | `A4` |
| Class | **`ratchet` → block** when surface grows; **`trigger`** when the contract **assembly** key is new |
| Analyzer | `GateEvaluator` (from `contractSurface`) |
| Commands | `gate` only |

## When it fires

For each assembly with role `contract`, surface = count of **public types** plus the sum of `PublicMembers` on those public types (public API member count).

- Value strictly greater than `baseline.ratchets.contractSurface[assembly]` → ratchet `contractSurface[{assembly}] {cur} > baseline {bas}`.
- Assembly not in the baseline map → trigger `new module/contract, review surface: {assembly}`.

Fingerprint: `ForTypeEdge("A4", assemblyName, "", [])`. The key is the **assembly name** (e.g. `Account.Contracts`), not the module id.

Removing members is not A4; disappearing public API with `--against` is [A8](A8.md). A new public type that only one foreign module uses is also [G2](G2.md).

## Example

```csharp
// Account.Contracts/IAuth.cs
public interface IAuth
{
    void Login(string user);      // already in baseline
    void LoginWithSso(string id); // +1 public member → A4 ratchet
}
```

A brand-new `Billing.Contracts` project with a first interface is an A4 **trigger** until baseline is updated.

## How to fix

1. Put new operations on the contract **only when another module needs them**. Internals of a feature stay in the implementation assembly.
2. Prefer extending an existing port carefully rather than publishing DTOs that leak persistence shapes.
3. When the growth is intentional (a versioned public API), run `arch-lens baseline` and commit it with the feature.

## What not to do

- Do **not** dump implementation types into `*.Contracts` to satisfy [A1](A1.md). That inflates A4 and usually [A5](A5.md)/[A6](A6.md).
- Do **not** add dummy `internal` wrappers in the contract assembly — A4 counts **public** surface only; hiding one member while adding two publics still ratchets.
- Do **not** reset baseline because “it's just one method”. That is the ratchet working.

See also [contractSurface](../metrics/contractSurface.md), [A5](A5.md), [A8](A8.md), [G2](G2.md).
