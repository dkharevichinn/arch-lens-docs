# C2 — Anemic contract or opaque body

| Field | Value |
|---|---|
| Code | `C2` |
| Class | `trigger` |
| Analyzer | `SizeBalanceAnalyzer` |
| Commands | `map` and `gate` (unless `knownFindings`) |

## When it fires

The module must have **at least one contract assembly** and **at least one implementation or infrastructure** assembly. UI types are not in the body count.

Let `contractTypes` / `bodyTypes` (implementation + infrastructure):

| Tag | Condition | Message |
|---|---|---|
| `anemic` | `contractTypes > bodyTypes` and `bodyTypes ≥ 1` | `anemic contract: {module}` |
| `opaque` | `bodyTypes ≥ 4 × contractTypes` and `contractTypes ≥ 1` and `bodyTypes ≥ 20` | `opaque body: {module}` |

Only one tag is emitted (anemic checked first). Modules with **no** contract are ignored (brownfield [A1](A1.md) mode).

Fingerprint: `ForTypeEdge("C2", moduleId, tag, [])`.

## Example

`Account.Contracts` with 12 public interfaces and `Account` with 3 classes → anemic. `Account.Contracts` with 2 interfaces and `Account` + `Account.Infrastructure` with 40 types → opaque.

## How to fix

- **Anemic:** shrink the published surface to what implementations actually honor, or grow the body so the contract is not a fantasy API.
- **Opaque:** split the body (submodules, extract infrastructure that should be a separate feature) **or** publish missing ports so the contract matches the real surface.

## What not to do

- Do **not** add empty contract types to “balance” opaque — that is [A4](A4.md)/[A5](A5.md) noise.
- Do **not** delete the contract project to escape C2; you lose the A1 legal path.

See also [C1](C1.md), [layerLoc](../metrics/layerLoc.md), [A4](A4.md).
