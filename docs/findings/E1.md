# E1 — God type

| Field | Value |
|---|---|
| Code | `E1` |
| Class | `trigger` |
| Analyzer | `TypeSmellAnalyzer` |
| Commands | `map` and `gate` (unless `knownFindings`) |

## When it fires

For scored types (not host/test), `score = distinct fan-in neighbors + distinct fan-out neighbors` (self-edges ignored). Median is over types with `score > 0`.

Fires when `score ≥ max(10, 2 × median)`. Cap **20**, order score desc then typeId Ordinal.

Fingerprint: `ForTypeEdge("E1", typeId, "", [])`. Message: `god type: {typeId}`.

## Example

A `HtmlDsmReporter`-style type that many types call and that itself calls many others can exceed `max(10, 2×median)` even if the module size is fine ([C1](C1.md) is module-level).

## How to fix

Split along responsibilities (render vs layout vs IO). Push neighbors behind ports. Prefer several types with clear edges over one omniscient type.

## What not to do

- Do **not** hide calls behind `object` / reflection so degree drops.
- Do **not** split into `Foo1`/`Foo2` that still form a dense clique ([D1](D1.md) dense).

See also [E2](E2.md), [C1](C1.md), [B7](B7.md).
