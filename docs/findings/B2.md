# B2 — Tangle percent ratchet

| Field | Value |
|---|---|
| Code | `B2` |
| Class | `ratchet` → **[block](../gates/block.md)** |
| Analyzer | `GateEvaluator` vs `baseline.ratchets.tanglePct` |
| Commands | `gate` |

## When it fires

`tanglePct = cyclicInterModuleWeight / totalInterModuleWeight` (0 if no inter-module edges). Fires when **current > baseline** (strict). Improvement does not auto-write the baseline.

Fingerprint: `ForTypeEdge("B2", "", "", [])` — one finding per repo.

Message: `tanglePct {current} > baseline {baseline}`.

## Example

A repo at 0% tangle grows a 2-cycle whose edges carry 10 of 50 inter-module weight → `tanglePct = 0.2`. If baseline was `0`, B2 blocks.

## How to fix

Remove or cut cyclic weight: the same work as [B1](B1.md). Reducing non-cyclic edges also changes the denominator — prefer breaking cycles rather than adding unrelated edges to “dilute” tangle.

## What not to do

- Do **not** add extra acyclic edges to inflate `totalInter` and shrink the ratio. That is metric gaming and still leaves the cycle for B1.
- Do **not** rewrite baseline because tangle “only went up a little”.

See also [tanglePct](../metrics/tanglePct.md), [B1](B1.md), [B3](B3.md).
