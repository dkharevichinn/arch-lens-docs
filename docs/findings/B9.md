# B9 — Shared gravity ratchet

| Field | Value |
|---|---|
| Code | `B9` |
| Class | `ratchet` → **[block](../gates/block.md)** |
| Analyzer | `GateEvaluator` vs `baseline.ratchets.sharedGravity` |
| Commands | `gate` |

## When it fires

`sharedGravity = (weight of inter-module edges **into** shared modules) / total inter-module weight`. Fires when current **>** baseline.

Fingerprint: `ForTypeEdge("B9", "", "", [])`.

`sharedTypeCount` is displayed alongside but is **not** this ratchet.

## Example

If half of all cross-module edges already point at `SharedKernel`, moving more feature types into shared (and adding more incoming edges) raises gravity and blocks.

## How to fix

Keep shared **small and stable**: primitive values, time, IDs. Feature policy stays in feature contracts. New cross-cutting types should be justified, then baseline updated **once**.

## What not to do

- Do **not** move a feature type into shared to legalize [A1](A1.md)/[A6](A6.md). You increased gravity and coupled everyone to that feature.
- Do **not** ratchet-reset after each “just one helper”.

See also [sharedGravity](../metrics/sharedGravity.md), [sharedTypeCount](../metrics/sharedTypeCount.md).
