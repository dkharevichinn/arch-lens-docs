# F1 — Tests past contract

| Field | Value |
|---|---|
| Code | `F1` |
| Class | **`ratchet` → block** when `testsPastContract` > baseline; **`trigger`** when the baseline key is missing, or on `map` when there is past-contract evidence |
| Analyzer | `TestTopologyAnalyzer` (map) + `GateEvaluator` (gate) |
| Commands | `map` (trigger + up to 10 evidence edges); `gate` synthesizes F1 and **ignores** the snapshot F1 row |

## When it fires

Edges whose source assembly is `role=test` and whose target is a **scored product** type. `past` = those edges whose target role is **not** `contract` and **not** `shared`. `testsPastContract = past/total` or 0 if total is 0.

**Map:** if there is at least one past edge, emit trigger F1 with evidence (heaviest 10 pairs). Fingerprint `ForTypeEdge("F1", "", "", [])`.

**Gate:** always skips snapshot F1. Then:

- `baseline.ratchets.testsPastContract` missing → trigger `new ratchet F1` (same fingerprint)
- current **>** baseline → ratchet message `testsPastContract {cur} > baseline {bas}`

A missing key is **not** treated as 0 (would immediately block old baselines).

## Example

```csharp
// Account.Tests
_ = new Account.AccountService(); // test → implementation: past
_ = default(Account.Contracts.IAuth)!; // test → contract: not past
```

If 8 of 10 test edge-weight units hit implementations, `testsPastContract = 0.8`. Baseline 0.5 → gate **block**.

## How to fix

Point tests at **contracts** (and shared test doubles of ports). Keep a thin adapter test if you must spin the composition root, but do not let the fraction grow.

## What not to do

- Do **not** delete tests to lower the fraction.
- Do **not** mark implementation assemblies as `contract` in YAML.
- Do **not** omit `testsPastContract` from baseline forever; the trigger exists so you **capture** the ratchet once.

See also [testsPastContract](../metrics/testsPastContract.md), [F2](F2.md).
