# E3 — Ceremonial interface

| Field | Value |
|---|---|
| Code | `E3` |
| Class | `trigger` |
| Analyzer | `TypeSmellAnalyzer` |
| Commands | `map` and `gate` (unless `knownFindings`) |

## When it fires

Scored `kind == "interface"` with:

- **exactly one** inbound `EdgeKind.Implementation` from a **scored** type
- **≤ 1** distinct scored `fromTypeId` among **other** inbound edges (calls, parameters, …)
- **and** no inbound non-implementation edge from a **host** type

Host assemblies (`role: host` in YAML, including Cli) count as consumers when deciding `otherFrom`. A 1:1 `*.Contracts` port injected only by the composition root (`ArchLensRuntime`, `ArchLensPipeline`, Cli) is a module port, not ceremonial. Test assemblies stay unscored: a mock does **not** count.

Zero scored implementations in-solution does **not** fire (implementation may live outside the snapshot, or only on Host). Cap 20.

Fingerprint: `ForTypeEdge("E3", interfaceTypeId, implTypeId, [])`. Message: `ceremonial abstraction: {iface} <- {impl}`.

## Example

```csharp
public interface IAccountService { void Run(); }
public sealed class AccountService : IAccountService { public void Run() { } }
// only AccountService implements it; only one other scored type injects IAccountService → E3
```

A port implemented once but injected in many scored types is **not** ceremonial (otherFrom.Count > 1). A port whose only production injector is Host is **not** ceremonial either.

## How to fix

If Host is the only production consumer, E3 does **not** fire — keep the interface as the module port. If there is no host consumer, no second implementation, and at most one other scored type uses the interface, **delete the interface** and use the concrete type (or a static) inside the same module. Keep the interface when it is a **module port** that other scored modules (or a future second adapter) should depend on — then give it a second production consumer, inject it from Host, or put it on `*.Contracts` **and** have Host or a second module consume it. Putting a type on `*.Contracts` alone does not suppress E3.

Test assemblies are not scored, so a “for tests only” mock does **not** count as a second consumer.

## What not to do

- Do **not** add a second fake implementation in production to dodge E3.
- Do **not** add a unused second consumer class.
- Do **not** treat every E3 as evil: a module-internal interface with one scored consumer can still be the right seam — accept the trigger, inject it from Host, or keep the interface at the **contract** boundary where multiple modules should consume it.
