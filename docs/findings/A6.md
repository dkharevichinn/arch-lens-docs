# A6 — Contract signature uses a foreign non-shared type

| Field | Value |
|---|---|
| Code | `A6` |
| Class | `trigger` |
| Analyzer | `ContractQualityAnalyzer` |
| Commands | `map` and `gate` (unless `knownFindings`) |

## When it fires

A type in a **contract** assembly has a signature edge to a type in **another module** whose role is **not** `shared`. Counted kinds:

- `parameter`
- `return`
- `fieldType`
- `genericArgument`
- `attribute`

**Not counted:** `call` (that is [A5](A5.md)); inheritance / implementation (hierarchy is left to [A1](A1.md)/[A2](A2.md) if the target role is illegal).

Same-module signature edges are ignored. `contract → contract` of **another** module **does** fire A6 (any type of module Y except shared). That is stricter than A1/A2, which allow contract→contract, and it is a trigger rather than a block.

Message: `contract signature uses foreign type {from} -> {to}`.

Fingerprint: `ForTypeEdge("A6", fromTypeId, toTypeId, sorted kinds)`.

## Example

```csharp
// Home.Contracts/NavArgs.cs
public sealed record NavArgs(Account.Contracts.LoginRequest Login); // A6: Home contract names Account contract type
```

```csharp
// Gameplay.Contracts/IScore.cs
public interface IScore
{
    Account.UserEntity Load(); // A6 + usually A2 if UserEntity is implementation
}
```

Using `SharedKernel.EmailAddress` in a contract signature is **legal** (target role `shared`).

## How to fix

1. Duplicate a **small DTO** in the consumer contract, or put a **shared** type in the declared shared assembly.
2. If Home really must speak Account's language, that coupling is explicit — keep it as a trigger you accept, or invert: Account consumes Home's nav types, not the reverse.
3. Never name EF entities, ViewModels, or infrastructure types on contract members.

## What not to do

- Do **not** move the foreign implementation type into Contracts to satisfy A2 and leave A6 behind — you still published a foreign module's shape.
- Do **not** add the target assembly as `shared` in YAML to mute A6. Shared is a kernel, not a junk drawer.
- Do **not** replace a parameter type with `object` / `string` JSON blobs to dodge the edge. That hides the coupling from the gate and from humans.

See also [A2](A2.md), [A5](A5.md), [contractSurface](../metrics/contractSurface.md).
