# B8 — Martin zone of pain or contract not abstract

| Field | Value |
|---|---|
| Code | `B8` |
| Class | `trigger` |
| Analyzer | `MartinMetricsAnalyzer` |
| Commands | `map` and `gate` (unless `knownFindings`) |

## When it fires

Per scored module, Martin metrics:

- `Ca = fanIn`, `Ce = fanOut`
- `I = Ce/(Ca+Ce)` or 0 if both 0
- `Na` = interfaces + abstract **classes** (abstract **records** are not abstract here)
- `A = Na/Nc` (0 if no types)
- `D = |A + I - 1|`

Two tags, mutually exclusive per module:

| Tag | Condition | Message |
|---|---|---|
| `pain` | **No** contract assembly, `I ≤ 0.3`, `A ≤ 0.3`, `Ca ≥ 2` | `zone of pain: {module}` |
| `concrete` | **Has** contract assembly and `A < 0.5` | `contract not abstract: {module}` |

Fingerprint: `ForTypeEdge("B8", moduleId, tag, [])`. Thresholds 0.3 / 0.5 are **code constants**, not YAML.

## Example

`Account` with `Account.Contracts` containing only concrete DTO classes (`A` low) → `contract not abstract`. A concrete `Helpers` module referenced by two others, itself depending on almost nobody (`I` low, `A` low) → `zone of pain`.

## How to fix

1. **Pain:** either make it truly abstract (ports) or stop treating a concrete bag of functions as a hub — invert so dependents own the port.
2. **Contract not abstract:** put interfaces/abstract ports in `*.Contracts`. DTOs can stay records; they do not raise `Na`.

## What not to do

- Do **not** add empty marker interfaces for every class to inflate `A`. That is [E3](E3.md) territory.
- Do **not** count abstract records as a fix — the analyzer ignores them on purpose (same port predicate as DI).

See also [martin](../metrics/martin.md), [A5](A5.md), [E3](E3.md).
